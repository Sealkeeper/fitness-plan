# fitness-plan · 训练计划 + 饮食计划

两份**单文件、可编辑、会自己保存**的 HTML —— 不是程序，是交付物：一份自己会看、会改、会长期用的东西。

打开浏览器就是一个页面，点「✏️ 编辑」改任何文字；改动写回文件本身，换台电脑打开还在。页面里所有能算的东西都替你算掉：训练表自动算每个大类、整套动作的总时长，饮食表按份量自动算热量与三大营养素。

- `训练计划.html` —— 我的训练（自由设计）+ 8 套训练日模板 + 身体数据记录 + 四条核心原则 + 动作库 + 肌肉与健康 + 3D 人体肌肉探索
- `饮食计划.html` —— 我的一天（自由搭配）+ BMR/TDEE 计算器 + 六套一日模板 + 电煮锅食谱 + 食物库 + 每日营养记录

建议直接打开 `训练计划.html`，左上角「训练 / 饮食」一键切换。

## 快速开始

### 想直接看

双击 `训练计划.html`。所有内容、包括 3D 模型都在文件里，不联网也能用；浏览器本地存档会记住你的修改。

### 想让它写回文件（推荐）

双击 `启动.bat`（需要装一次 [Python](https://www.python.org/downloads/) 并勾选 "Add python.exe to PATH"），或手动：

```bash
python serve.py
```

它会把这个文件夹当静态站点跑在 `127.0.0.1` 的某个端口上，并打开页面。在页面上改的东西**直接写回 .html 本身** —— 不再依赖某个浏览器，换个浏览器、换台电脑（同步文件夹）都还在。

- 只监听本机回环地址，外网访问不到
- 只能写这个文件夹里的 `.html`，写不进别处
- 保存前会核对文件指纹：文件在页面打开后被别的程序改过，就拦下这次保存，不覆盖
- 端口被系统动态保留（Hyper-V / WSL / Docker 会圈走一些段）时自动换下一个

## 怎么用

**训练表**：先在上面「⭐ 我的训练」里点「＋ 添加方案」，然后从「从模板填充」挑一套（全身 A/B/C、颈部、薄肌推拉腿、代谢循环），整张表连组数、次数、间隔一起复制进来，之后随便改。也可以自己往大类里加动作 —— 动作名有下拉候选，选中就自动带出动作要点。

**饮食表**：先在「第一步」填体重/身高/年龄，页面立刻给出 BMR、TDEE 和三种目标的宏量分配；再到「我的一天」用模板或手动填，四列营养自动算。

**记录表**：训练页记体重 / 体脂率 / 肌肉率，饮食页记体重 / 腰围 / 热量与三大营养素。按周、双周、按月筛选，也可以跳到今天、往后补排。

**导出 / 导入**：右上角「⬇️ 导出」把当前状态存成一份完整 HTML，「⬆️ 导入」再读回来 —— 这两条路都不需要本地服务。

```

启动.bat              Windows 双击启动
anatomy/              3D 探索区的源码（界面、肌肉库、健康内容、构建脚本）
  viewer.js           界面、Three.js 场景、拾取、模型解码
  muscles.js          肌群筛选、中文位置/功能说明、网格名称匹配
  health.js           肌肉健康关联、健康主题与文献来源
  viewer.css          桌面与移动布局
  build.mjs           把源码打进 训练计划.html（别手改生成的 runtime 块）
  prepare-models.mjs  从原始解剖模型重建压缩后的模型数据
  verify.py           浏览器回归检查（需 playwright + chromium）
assets/anatomy/       解剖模型数据与第三方许可说明
```

## 修改 3D 探索区

```bash
cd anatomy
npm ci
npm run build
```

构建会把 `viewer.js` / `muscles.js` / `health.js` / `viewer.css` 打进 `训练计划.html` 里生成的那几块。改完请跑一遍回归检查：

```bash
python verify.py --chromium /usr/bin/chromium
```

检查健康主题、名称覆盖、筛选与三维跳转、深层肌群、动作弹窗、保存隔离、断网时的单文件完整性、重复导出与手机布局。测试使用只读临时服务，不会把修改写回原文件。

## 关于内容

页面里的训练与饮食内容基于公开的运动科学文献与临床常识整理，**不构成医疗诊断或治疗建议**。动作库、肌肉库与健康主题都注明了依据与适用范围；相关健身动作不等于康复处方。任何训练中出现的尖锐疼痛都应立即停止并就医。

仓库里带的是**通用模板**：个人档案、身体数据、你填过的方案都不在里面 —— 那些是你自己的东西，用页面填、用页面的自动保存留着就好。
